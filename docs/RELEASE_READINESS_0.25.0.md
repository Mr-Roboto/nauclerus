# Nauclerus 0.25.0 release readiness

Stable publication of the accepted RC13 implementation is explicitly authorized.
See [release validation](RELEASE_VALIDATION_0.25.0.md),
[ACID reference evidence](ACID_GOLDEN_0.25.0.md),
[asset audit](ASSET_AUDIT_0.25.0.md), [licensing](../LICENSING.md) and
[security baseline adoption](NAUCLERUS_SECURITY_BASELINE_ADOPTION.md).

RC11 passed owner-reported physical acceptance (10/11), with the subjective
resonance/filter concern accepted. RC12/RC13 added compatible routing/magnitude
semantics. Promotion to stable adds no DSP or musical behavior. Package protocol
is FM-1_25000; FDRF remains3840bytes, with original Song/lock formats and preset IDs.

BIP retains exact signed-depth arithmetic. UNI+ and UNI− use unsigned0–100% DEPTH;
legacy negative UNI values retain magnitude with no phase reversal. All four
slots preserve existing parameter IDs, source decoding, MIDI Learn and storage.

ORB provenance is resolved by Mr. Roboto's independent-authorship/redistribution
declaration. Future Retro Orb is conceptual inspiration only. Retained code notices
and all third-party licenses accompany artifacts. Five unverified optional images
are excluded, without replacing runtime assets or altering original local files.
